# 마이페이지와 권한 관리 UI

## 마이페이지

- `/mypage`: 프로필, 출석 통계, 출석 이력, 알림 설정 및 권한 설정 이동.
- 알림 기본값은 세션 시작 알림 끔, 새 공지 알림 켬입니다.
- 알림 선택은 `sdp-preview-notifications-v1`에 저장하며 새로고침 후에도 유지합니다. 실제 알림 구독·전송은 연결하지 않았습니다.
- 로그아웃 확인창에서 취소하거나 Escape를 누르면 화면에 남습니다. 확인하면 `/onboarding`으로 이동합니다. 인증 세션 종료 API는 추후 연결해야 합니다.
- 이름·통계·출석 이력은 `src/mocks/profile.ts`의 샘플 데이터입니다.

## 권한 관리

- `/admin/permissions`: 전체 샘플 학회원 목록을 표시합니다.
- 기수 선택 시트에서 16~19기를 선택하면 해당 기수로 필터링합니다. 선택된 기수는 시트에 체크 표시로 나타납니다.
- 부여·해제는 확인창을 거치며, 취소하면 데이터를 바꾸지 않습니다.
- 변경은 브라우저의 `sdp-preview-members-v1` 샘플 데이터에만 저장합니다. 실제 관리자 권한 변경이나 접근 제어를 수행하지 않습니다.
- 학회원 수는 샘플 데이터에 따르므로 기수를 선택한 뒤 표시되는 인원은 화면 예시와 다를 수 있습니다.

## 연동 대기

프로필 조회, 출석 내역 조회, 알림 구독, 로그아웃, 관리자 권한 조회·변경 및 서버의 권한 검증은 API 연동 단계에서 연결합니다.
