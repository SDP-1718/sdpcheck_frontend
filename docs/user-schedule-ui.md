# 사용자 일정 UI

`/schedule`은 홈의 다가오는 일정 및 더보기에서 진입합니다. 상단 뒤로 버튼은 홈으로 돌아갑니다.
관리자 일정과 동일한 `sdp-preview-schedules-v1` 데이터를 날짜·시간순으로 정렬하여 월별로 표시합니다.
월 제목과 날짜 타일은 실제 저장된 날짜를 사용합니다. 여러 해가 섞이면 월 제목에 연도를 함께 표시합니다.
목록이 비어 있으면 빈 상태 안내를 표시하고, 잘못된 날짜 데이터는 목록에서 제외합니다.
디자인의 9·10·11월 반복 항목은 표시 예시이며 실제 항목 수는 저장된 일정에 따릅니다.
현재는 로컬 UI 미리보기이며 서버 API 연결이 필요합니다.
