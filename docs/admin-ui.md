# 관리자 UI 및 API 연결 전 확인 사항

## 화면
- 세션: 빈 목록, 생성, 달력·시간 선택, 매주 반복 요일 선택, 시작, 카운트다운, 종료 상태.
- 공지: 목록, 상단 고정, 작성·수정·삭제, 삭제 확인, AI 초안 요청 중·실패 상태.
- 일정: 목록, 등록·수정·삭제와 날짜·시간 선택.
- 통계: 샘플 요약·출석 추이, 부원 출석률 정렬, CSV 내보내기.

## 로컬 미리보기
데이터는 `sdp-preview-*` 브라우저 저장소에 보관합니다. 실제 서버 데이터나 권한을 변경하지 않습니다.
세션 QR은 디자인 확인용 정적 이미지이고 체크인 명단과 전체 통계·차트는 샘플입니다.
57초 카운트다운은 화면 상태 확인용입니다. 실제 QR 만료·갱신 및 세션 종료 정책은 서버 연동 때 연결해야 합니다.
반복 요일은 설정만 저장하며 반복 세션을 자동 생성하지 않습니다.

AI 초안은 `NoticeEditor`의 `generateDraft` 어댑터 연결이 필요합니다. 연결 전에는 실패 안내 후 직접 작성할 수 있습니다.
API 연결 시 요청 취소·권한 검사·서버 오류와 중복 제출 처리를 함께 적용해야 합니다.

`엑셀로 내보내기`는 UTF-8 BOM을 포함한 Excel 호환 CSV를 내려받습니다. XLSX 파일은 아닙니다.
목록에는 디자인에 맞춰 상위 4명을 표시하고 CSV에는 정렬된 전체 부원을 포함합니다.
쉼표·따옴표·줄바꿈을 이스케이프하고 수식으로 해석될 수 있는 텍스트에 보호 문자를 추가합니다.

## 확인
`npm run build`, `npm run lint` 및 브라우저에서 세션 상태 전환, 중첩 선택창 닫기, 공지·일정 CRUD,
CSV 다운로드, 320/375/402/768px 가로 넘침과 선택창 종료 후 스크롤 복원을 점검합니다.
