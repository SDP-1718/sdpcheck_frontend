# 회원정보 입력 UI

`/onboarding/profile`에서 이름·기수·초대코드를 입력합니다. 기수는 16~19기 선택창으로 선택합니다.
공백만 있는 이름·초대코드는 제출할 수 없으며 초대코드 오류 시 입력값을 유지합니다.
성공 시 `/onboarding/complete` 환영 화면을 1.5초 표시하고 홈으로 이동합니다.
입력한 이름·기수는 홈과 마이페이지에 함께 표시하고 로그아웃하면 제거합니다.

## API 연결 전
현재 카카오 버튼은 회원정보 UI로 이동합니다. 실제 카카오 인증을 수행하지 않습니다.
개발 모드에서만 초대코드 `SDP2026`으로 로컬 UI 성공 흐름을 확인할 수 있습니다.
이는 디자인 예시의 테스트 코드이며 실제 가입·초대코드 검증이나 권한 부여를 수행하지 않습니다.
배포 빌드에는 기본 성공 처리가 없고 안내 메시지를 표시합니다.
실제 연결 시 `MemberInformation`의 `registerMember`에 인증된 등록 API를 전달하고 카카오 OAuth 완료 후 진입시킵니다.
초대코드 오류는 `RegistrationError('invitation')`, 통신·서버 오류는 일반 오류 또는 `unavailable`로 처리합니다.
초대코드 자체는 브라우저 저장소에 보관하지 않습니다. 미리보기 이름·기수만 저장합니다.
